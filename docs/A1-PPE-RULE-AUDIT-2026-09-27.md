# A1 口罩/手套实验规则交付审计

## 实现范围

- 新增 A1 `员工未规范佩戴口罩或手套` 实验规则。
- 上传页可独立选择 E1/A1 与逐帧基线/双层判定，形成规则和分析模式的正交组合。
- 逐帧基线：1 fps 全量观察。
- 双层判定：0.2 fps 视频粗筛疑似区间，再在区间内均匀抽取 5 个关键帧复核。
- A1 只在操作区人员脸部或双手清晰可见时判断；遮挡、背身、距离过远或路过返回 `unknown`。
- 最近 5 个有效观察至少 3 次违规才生成事件；连续 3 次合规视为恢复。
- A1 固定为 P2 实验规则，后端强制不发送飞书通知。
- 事件保留开始、确认、峰值和恢复证据，并可在原视频时间轴跳转。

## 产品逻辑审计

- 模型只输出可见事实、可见度和候选状态，不决定严重度、通知或最终事件。
- 口罩和手套只有对应身体区域清晰时才允许判断，避免把遮挡误判成未佩戴。
- “口罩已佩戴但手部不可见”不会被系统判为完全合规，而是证据不足。
- A1 与正式规则分组展示，不纳入当前准确率承诺。
- AI 生成视频只能作为流程与压力测试样本，不能替代真实门店准确率验证。

## 自动化测试证据

- A1 3/5 聚合、恢复与不足命中测试。
- 口罩违规可见证据与手部遮挡测试。
- A1 逐帧端到端事件测试。
- A1 双层粗筛 + 5 个关键帧复核测试。
- API 规则快照测试。

最终执行结果：后端 26 项、前端 9 项及生产构建全部通过。

## 下一段正样本视频要求

- 固定监控机位，前台或后厨操作区，员工脸部和双手在多数时间内清晰可见。
- 0–5 秒无人或合规员工；5–20 秒员工进行真实制作动作，明确未戴一次性口罩且未戴一次性手套；20–30 秒员工正确佩戴后继续操作。
- 不使用背身、远距离、手部被操作台长期遮挡的构图。
- 不同时加入冰箱门、积水、烟雾等其他异常，避免规则串扰。
- 同时准备一段全程规范佩戴的负样本，才能评估误报率。

## 已知缺口与未通过门槛

- 当前没有口罩/手套清晰可见的正样本视频，因此尚未通过真实模型正样本验收。
- 当前火山引擎接入点处于 429 限流状态，A1 真实负样本尚未跑出模型结论；待额度窗口恢复后可直接重放。
- 当前负样本是 AI 生成的冰箱门场景，不代表真实门店摄像头分布。
- 在取得正样本、合规负样本和遮挡样本前，A1 不升级为正式规则、不发送飞书告警。
