## 原型字体与样式复验（用户指出前次验收不充分后的补测）

前次记录只检查“可见、可点击”，未量测字号和组件内部排列，不能视为视觉验收通过。这次读取 `prototypes/visual-baseline-v1/components/CameraManagementPage.jsx` 和 `DashboardPage.jsx` 的原始样式，在浏览器同视口核对计算后样式：

| 部位 | 原型值 | 前次实现 | 本次修正 |
| --- | --- | --- | --- |
| 摄像头页标题 / 说明 | 22px / 13px | 21px / 11px | 22px / 13px |
| 指标卡 | 40px 图标在左；标签 11px、数值 18px | 图标在右；数值 19px | 图标在左；11px / 18px |
| 列表表头 / 正文 | 12px / 13px | 10px / 11px | 12px / 13px |
| 摄像头名称 / 编号 | 13px、600 / 11px 等宽 | 11px、700 / 9px | 13px、600 / 11px 等宽 |
| 状态 / 最后心跳占位 | 12px、500 / 12px 等宽 | 11px / 10px | 12px、500 / 12px 等宽 |
| 首页 KPI | 灰色细边框；12px 标签、28px 数字、12px 说明 | 彩色顶边；12px、28px、11px | 灰色细边框；12px、28px、12px |

浏览器实测：摄像头页在 1355×742 与 1280×720 均显示四行主表、三卡、按钮和开关；1280×720 的 `documentWidth=1280`、主表 `scrollWidth=1006 < clientWidth=1008`，没有横向溢出，四张封面全部加载。首页在 1280×720 显示四张 KPI 与四宫格，图片无断图，KPI 标签/数值/说明计算字号为 12/28/12px。

交互与异常路径：打开「添加摄像头」弹窗并确认名称/编号必填及键盘焦点可见；没有向真实库提交新来源。临时停止本地 8797 API 后刷新，页面不再无限转圈，而是显示中文错误和「重新加载」，顶栏同步显示连接异常；恢复 API 后点击重试返回 3/4 主表。先前的开关 3/4→4/4→3/4 已在真实页面与持久化接口核实。

验收结论：本轮摄像头页与首页上述文字、字号、排列和基础交互通过；并不等于整个 MVP 产品验收通过。原型中的设备型号、心跳、分辨率、在线时长与实时流量仍无真实设备来源，因此保持“未接入/实际上传量”而不复制 Mock 数字。空数据和无权限状态尚无对应可运行环境与截图回归基线，列为后续验收门槛。
