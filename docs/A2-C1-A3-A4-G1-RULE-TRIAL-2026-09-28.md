## 模拟与验证

使用可复现的测试替身注入模型观察，未向付费模型发请求，Token 消耗为 0。A2/C1/A4 的 5 帧违规样本各产生 1 条待复核事件，`unknown` 或合规样本产生 0 条；A3 的 50 秒脏乱样本产生 0 条、61 秒样本在第 60 秒确认 1 条。以上均不产生通知记录。

G1 注入「顾客离席且餐桌有残留」和「顾客仍在座」两种 50 秒观察，两者都产生 0 条超时事件；125 秒离席残留模拟在第 120 秒产生 1 条实验待复核事件，不发送通知。这验证的是**后端时序聚合**，不证明视觉模型能在此前 LibTV 视频中正确识别顾客离席与残留。两条成片保存在 `assets/generated/video-tests/`，未导入站点视频库；本次核对了两条视频的接触表，但没有向付费模型提交真实视频分析任务，也未在页面伪造结果。两条视频不是同一餐桌机位对照，末段还存在末帧延长，不能据此验收实际时序识别准确率。

对这两条实际文件读取的视频时长均为 50.0 秒；按人工标注为正片 `0–6s=occupied`、`7–49s=departed_residual`，负片 `0–49s=occupied`，输入 `TimedObservationAggregator('departed_residual', 120, 2.5)` 后，两条均输出 `0` 个事件。这是文件时长 + 人工标注驱动的模拟，不是模型推断。
