## 已知边界

- 这是公开链接；`noindex` **不是**密码或访问控制。现有数据只用于合成样本演示，未来若要展示真实门店画面，须先完成脱敏和访问权限设计。
- 历史事件沿用其创建时记录的 P1/P2 等级，不把历史数据悄悄改写成后来规则的新等级；规则页展示的是当前规则配置。尤其 E1 规则现定为 P0，旧 E1 事件仍可能为 P1。
- 任务列表中的历史成本仅为模型费用估算；不等于 Cloudflare 帐单。
- Pages 静态资源在 Cloudflare 当前免费计划内可用，但仍受其免费计划限制；未来若接实时视频、可写工单或云端 AI API，需要单独设计后端和成本控制。静态版不调用这些服务。
- Direct Upload 项目不能直接改为 Git 自动集成；若以后需要 Git 自动部署，应新建 Git 集成项目或使用 CI 调用 Wrangler 上传。
