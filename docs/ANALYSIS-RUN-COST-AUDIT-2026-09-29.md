# 视频分析任务模型成本验收（2026-09-29）

## 口径

- 每条分析任务按记录的输入、输出 Token 分别计价，公式为 `输入 Token × 输入单价 / 1,000,000 + 输出 Token × 输出单价 / 1,000,000`。
- 采用[火山方舟模型定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)的常规在线推理公开价：Doubao Seed 2.1 Lite 非音频输入 ¥0.80/百万 Token、输出 ¥2.70/百万 Token；Pro 非音频输入 ¥6.00/百万 Token、输出 ¥30.00/百万 Token。
- 当前只估算视觉 AI 模型推理费，不是服务商账单。未扣除缓存、免费额度或协议折扣，也不含视频生成、视频存储、转码、网络和人工费用。
- 新任务保存模型响应中的模型 ID。旧任务若有 Token 但模型 ID 未留档，展示按已知 Lite/Pro 价格计算的区间，不臆测单一金额；未记录用量时展示“用量未记录”或“暂无可核算用量”，不显示 ¥0。

## 页面与接口

- 分析任务每行视频名下显示“模型成本：约 ¥…”；模型未留档显示估算区间。
- 任务详情展示模型成本、计价模型和口径说明，链接到官方价格页。
- `/api/runs` 与 `/api/runs/{run_id}` 返回成本状态、估算金额或区间。历史帧响应有模型 ID 时回填用于展示，不改写旧数据。

## 已知限制

- 早期任务未记录模型或用量，无法凭现有数据还原精确历史支出。估算区间只覆盖本项目已观测到的 Lite/Pro 模型，不代表所有可用模型的价格范围。
- 若后续请求发生混用模型、走缓存优惠或调整价格，本估算与实际账单会有差异；要实现财务对账，需接服务商账单和逐请求用量明细。
