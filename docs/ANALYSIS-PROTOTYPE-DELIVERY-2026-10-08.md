# 分析任务原型交付测试 — 2026-10-08

## 原型与实现
- 来源：用户附件 门店视觉巡检 Demo (4).zip 内 components/AnalysisTaskListPage.jsx，及用户提供分析任务截图。
- 使用原型20px标题、12px说明、白色选中Tab、6px分组容器、SVG视频/图片图标及真实数量。
- 固定五列：任务/素材、规则/类型、进度、结论/状态、数量/调用/时间。14px×16px行内边距、6px进度条、紧凑11–12px正文；末列右对齐。
- 独立16px筛选卡，规则标签按原型顺序；同一完整规则集合供三个Tab使用，不随类型缩减或增加。用户图片规则也保留。
- 全部/视频/图片复用同一表格；保留状态/规则/时间/搜索筛选和统一分页。图片结论使用真实通过/不通过/核查/补拍，不伪装为视频异常。
- 旧图片任务没有创建时间时，用已记录的完成时间排序，并以提示明确；不补造缺失时间。后台最近菜单 IMG-TASK-b7c6bea329c2 已确认存在。
