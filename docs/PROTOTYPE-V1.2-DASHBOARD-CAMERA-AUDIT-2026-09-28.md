# 门店原型 v1.2：监控大盘与摄像头详情验收

## 实现范围

- 收录并版本化用户提供的 v1.2 原型；旧版基线保留。
- 首页改为四张 KPI、整行 2×2 监控矩阵、下方横向异常事件流。每个监控画面可键盘聚焦并点击进入对应摄像头详情。
- 摄像头详情按原型的面包屑、左侧大画面、右侧设备信息与统计、下方异常记录组织。记录支持今日、近 7 日、近 30 日；事件可进入真实证据详情并返回摄像头。
- 左侧“总览 / 工具 / 运营”分组保留，并校准分组标题样式。额外的分析任务、规则配置入口按现有工程需要分别放入工具、运营组。
- 原型中的假直播、REC、固定时钟、IP、心跳、播放与音量按钮不照搬。画面明确为合成演示静帧；设备字段未接入时显示“未接入”。

## 产品逻辑核查

- `/api/cameras/{id}/detail` 按门店和摄像头过滤，使用 Asia/Shanghai 当地日历日计算 1/7/30 日窗口；统计排除误报与忽略，记录仍保留它们供审计。单次最多返回最近 200 条记录。
- 首页 KPI 仍由现有真实任务、事件和视频源配置计算。`4/5` 是全部五个虚拟视频源的可用状态；大屏只展示原型四宫格，故另标 `3/4 路已启用`。两者不是物理摄像头在线率。
- 原型中的 AI 准确率、设备流量和多门店健康分暂无可靠分母/接入，不以模拟数字代替。工单原型的自动派单、SLA 逐级升级亦未实现；当前仅保留真实事件关联的人工指派闭环。

## 自动测试与浏览器验收

- `./scripts/verify.ps1`：44 项 Python 测试、21 项前端测试、Vite 生产构建和 `git diff --check` 通过。使用已安装 FastAPI 的 Python 3.10 执行。
- 新增 API 测试覆盖摄像头隔离、今日与七日时窗、误报不计入统计、非法天数与不存在摄像头。
- 右侧浏览器在 1280×720 核验：首页 2×2 封面、三组导航、点击前台空记录、七日筛选、点击后厨真实 B1 记录、进入事件页并沿面包屑返回。详情页 `documentWidth=1280`，与视口一致；静帧与证据缩略图均加载成功。

## 未通过 / 待补

- 原型详情的真实视频播放、心跳、设备型号、IP、分辨率与物理在线率依赖后续摄像头接入；当前仅有虚拟视频源配置。
- 门店总览多门店指标和工单自动派单/SLA 升级尚不具备真实后端能力，不在本次验收范围。
- 无权限、超长记录与 200 条上限状态没有端到端截图回归；本次验证覆盖加载、空记录、已完成事件与 API 单元错误分支，不代表全站产品验收完成。
