# 真实门店分析成本优化交付审计（2026-10-06）

## 实现
- M1 粗筛从 1 fps 降到 0.2 fps。首中尾不足两帧时补查区间四分位关键帧，保持两个不同时间点明确拖地才通过。
- G2 尊重上传页选定模式，双层默认粗筛 0.2 fps；每段复核在座及离席后连续关键帧，仍要求先前在座与连续三次残留观察。最多八个候选；低质量/粗筛失败暂停请求回退，不自动花费逐帧费用。
- analysis_usage 持久化每次成功响应的阶段、模型和输入输出 Token，结果页按阶段展示调用与估算成本。原有总计保留。
- 回退模式统一显示“双层 → 逐帧回退”；新任务累计各次实际处理耗时、保留首次开始时间，排除确认等待。旧任务缺少第一轮实际耗时，展示创建到完成总历时并标明含排队及确认等待，无法恢复的阶段标明未保存。
- 金额沿用现有公开价估算，不代表火山账单。
