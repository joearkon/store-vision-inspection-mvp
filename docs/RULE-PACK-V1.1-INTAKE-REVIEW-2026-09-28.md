## 与旧包相比已修正

- A1 恢复为未戴口罩/一次性手套，F1 恢复为取餐区堆积混乱，F2 恢复为排队拥挤；新提出的通道堵塞、生熟混放、异物混入分别改为 A6、F3、F4。历史事件编码无需迁移。

- 因此 v1.1 可作为下一轮规则样本设计的基线，但**不自动激活** A6/F3/F4 或其他未实现规则。

## 可直接吸收的测试思路

- B1 正样本要配蒸汽、反光、受控火焰等压力负样本；A2/C1 要排除遮挡与非员工；A3/A4 要排除清洁中和正常制作过程；G1 要绑定逐桌 ROI 与离席/清理时序。
- Golden Set 的事件时间段、证据位置、人工复核字段可作为标注 schema 草案；合成视频需人工初筛，不可直接当真实门店准确率。
