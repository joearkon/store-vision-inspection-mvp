# 项目章程

## 产品定位

为总部巡检运营、区域督导和门店负责人提供独立的 AI 视频巡店、异常证据、飞书告警与整改追踪系统。

## MVP 范围

1. 本地 MP4 上传分析。
2. 预置视频自动循环演示。
3. FFmpeg 按配置抽帧。
4. 豆包 Vision 结构化判定。
5. 连续至少三帧命中后确认事件，并执行时间窗口去重。
6. 事件 Dashboard、详情和证据查看。
7. 严重事件飞书交互卡片。
8. 独立组织、区域、门店、账号、角色和数据范围初始化。

## 暂不纳入

- 与加盟商运营系统实时同步。
- 摄像头 RTSP 长连接接入。
- 大规模分布式任务队列。
- 自动处罚或完全自动关闭整改事件。

## 待原型评审确认

- 异常规则及证据标准。
- 模型输出 JSON Schema 和置信度阈值。
- 事件合并、解除和重复告警规则。
- 视频与证据保留期限。
- 飞书卡片动作和整改状态机。
- 页面状态、移动端/桌面端视口及视觉契约。
