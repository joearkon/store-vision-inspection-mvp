# 独立 UI 审核：机位关联控件与相关页面

2026-10-06。审核方式为真实 Edge 浏览器渲染、计算样式断言及截图人工查看，没有使用模型生成的界面效果图，也未触发视频上传或外部模型调用。

## 发现与修正

用户截图所示机位选择框确实存在缺陷。旧 `.upload-card .form-block select` 的选择器优先级覆盖新 `.auto-upload-grid select`，使其实际字体为16px、高度42px。此前仅检查运营配置选择框的计算样式，遗漏上传页来源关联展开状态，因此此前审核不足。

修正限定在自动上传页：选择框实际12px字体、36px高度、1px细边框，与同页表单密度一致；使用线性SVG下拉箭头；补充hover、键盘focus-visible和disabled状态。来源关联折叠标题使用轻量箭头，保留折叠行为、键盘访问及可选机位关联功能。业务规则、任务结果和运营配置未改变。
