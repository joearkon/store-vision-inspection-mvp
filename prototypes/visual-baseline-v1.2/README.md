# 视觉原型基线 v1.2

本目录为用户提供的 `门店视觉巡检 Demo (3) v1.2.zip` 的校验后展开副本，只用于设计、交互和差异对照，不作为生产源码运行。正式实现位于 `apps/web/`。

相对 v1 的主要变化：监控大盘改为整行监控矩阵和横向异常事件流；新增可点击的摄像头详情；事件详情面包屑可返回摄像头；左侧导航按“总览 / 工具 / 运营”分组；门店总览和工单仍含模拟经营数据与自动派单、升级演示。

原型中的 `LIVE`、`REC`、固定时间戳、心跳、IP、健康分、识别准确率和自动派单不能直接当作真实系统数据。实现时遵循 `docs/MVP-SCENARIOS-TECHNICAL-DESIGN.md` 的业务边界。
