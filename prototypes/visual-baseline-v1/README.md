# 视觉原型基线 v1

本目录是 `references/original-v1/门店视觉巡检 Demo.zip` 的展开副本，用于：

- 查阅页面结构、布局、颜色、字号、间距与交互；
- 执行后续页面的视觉截图对照；
- 追溯原型中的 Mock 数据和页面状态。

它不是生产应用源码。原型依赖浏览器运行时 Babel 和远程 CDN，正式应用应在 `apps/web/` 内使用工程化构建，但视觉结果必须遵守 `docs/VISUAL-IMPLEMENTATION-CONTRACT.md`。

除修复原型自身无法打开的问题外，不在本目录继续开发业务功能。所有新增页面与真实后端对接均进入正式应用目录。
