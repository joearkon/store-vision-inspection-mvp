## 主样本 Prompt（Positive）

### F3-POS-01 · 生食与即食物料同台面摆放

```
固定监控摄像头视角，竖屏 9:16，俯视后厨操作台。
不锈钢操作台左侧放着一碗切好的生水果（西瓜、芒果块），无遮盖。
操作台右侧放着几杯已制作完成、待封盖的奶茶（杯口敞开）。
生水果碗与奶茶杯距离约 15cm，无分隔板或保鲜膜隔离。
一名员工的手从生水果碗方向移向奶茶杯方向，未更换手套。
真实监控画质，固定机位，白天，顶灯照明。
```

**标注要点**：
- event_type: `cross_contamination`
- bbox: 生食区域 + 即食食品区域
- severity: `major`
- 注意：生食/即食的物理距离、是否有隔离措施、人员操作是否换手套

```
固定监控摄像头视角，竖屏 9:16，侧视冰箱内部（冰箱门打开状态）。
冰箱上层架放着几杯已封盖的成品奶茶和几盒切好的水果。

真实监控画质，固定机位，白天，冰箱内部照明。
```

**标注要点**：
- event_type: `cross_contamination`
- severity: `major`

## 负样本 Prompt（Negative）

### F3-NEG-01 · 规范分区域存放

```
固定监控摄像头视角，竖屏 9:16，俯视后厨操作台。
操作台分为左右两区：左侧「生食区」有切好的水果，上方有透明保鲜膜覆盖，旁边有红色「生食」标识牌。
右侧「即食区」有制作中的奶茶，两区之间有不锈钢隔板分隔，间距约 20cm。
员工操作生食后更换手套再接触即食区。
真实监控画质，固定机位，白天。
```

**关键区分点**：明确分区 + 物理隔离 + 操作规范

## 边界 Case Prompt（Edge）

### F3-EDGE-01 · 同区域但已密封包装

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台上有已密封的生鸡蛋（塑料盒密封）和已封盖的奶茶杯，两者距离约 10cm。
生鸡蛋密封完好，无破损，无液体渗漏。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.55，密封包装的生食与即食混放是否算违规？——建议：密封完好且未破损可豁免

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `cross_contamination` / `compliant` + 置信度 + 区域 bbox |
| **Layer 2** | confidence 0.60-0.85 | 抽帧 → 放大操作台区域 → 二次判定生食/即食类型和隔离状态 |
| **后端规则** | Layer 2 确认混放且无隔离措施 | 触发告警；如员工未换手套操作两者直接 Major |
