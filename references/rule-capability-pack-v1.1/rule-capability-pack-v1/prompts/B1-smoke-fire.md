# B1 · 烟雾 / 明火检测 · Video Prompt

> 规则编码：B1 | 优先级：P0（高危安全事件）
> 对应 MVP §4.1 正式规则 | 检测目标：后厨/操作间/仓库区域的烟雾、明火、异常高温发光体

---

## 通用参数（所有样本共用）

| 参数 | 值 | 说明 |
|------|-----|------|
| 分辨率 | 1080×1920 | 竖屏 9:16，模拟真实门店摄像头视角 |
| 帧率 | 30 fps | 标准帧率，保证运动连续性 |
| 时长 | 主样本 8-10s / 负样本 5-8s / 边界 6-10s | 受平台限制时按平台上限调整 |
| 风格 | 真实监控摄像头风格 | 无滤镜、无电影感、固定机位、轻微噪点 |
| 光照 | 见各样本具体描述 | 覆盖白天/夜间/逆光 |
| 参考图 | `./artifacts/user_photo_20260927.jpg`（EZVIZ MOMOYO JTU 门店实拍基线） | 保持与该图一致的门店装修风格、色调、设备布局 |

### 平台限制提醒

- **豆包视频生成**：单段 ≤ 10s，支持文生视频，建议分镜描述清晰
- **可灵**：单段 ≤ 10s，运动表现较好，适合烟雾飘动场景
- **海螺**：单段 ≤ 10s，画面稳定，适合固定机位监控风
- **Minimax**：单段 ≤ 5s，需拼接多段或缩短单段时长

> ⚠️ **关键约束**：生成视频必须为固定机位、无镜头运动、无切换，模拟真实安防摄像头画面。

## 主样本 Prompt（Positive）

### B1-POS-01 · 操作台后方明火（白天）

```
固定监控摄像头视角，竖屏 9:16，俯视 slightly 斜视后厨操作台。
奶茶店后厨环境，不锈钢操作台，上方有抽油烟机。
画面中央偏右，一名员工正在操作台前备料。
突然，操作台后方角落的电气设备冒出明火，火焰高约 15-20cm，橙黄色，带有黑色烟雾向上窜动。
员工发现后转身查看，表情惊慌。
真实监控画质，无滤镜，室内白天自然光+顶灯，画面略有噪点。
```

**标注要点**：
- event_type: `flame`
- start_frame: ~60 (2s 左右首次出现明火)
- severity: `critical`
- 注意：火焰颜色、高度、烟雾颜色的真实感

---

### B1-POS-02 · 垃圾桶阴燃烟雾（夜间）

```
固定监控摄像头视角，竖屏 9:16，俯视门店角落的垃圾桶区域。
夜间闭店后场景，仅保留安全出口指示灯和少量氛围灯照明，画面偏暗但可辨识。
垃圾桶为带盖不锈钢分类桶，位于画面右侧。
桶盖边缘缓慢冒出灰白色烟雾，呈细条状向上飘散，无火焰可见。
烟雾持续稳定冒出，无明显间断。
真实监控夜视画质，红外补光效果，画面有轻微颗粒感，无运动镜头。
```

**标注要点**：
- event_type: `smoke`
- start_frame: ~30 (1s 左右烟雾可见)
- severity: `major`
- 注意：阴燃无火焰，只有烟雾，颜色偏灰白

---

### B1-POS-03 · 油炸区油雾爆燃（白天高峰期）

```
固定监控摄像头视角，竖屏 9:16，正对后厨油炸区。
奶茶店后厨，不锈钢油炸锅位于画面中央，油温过高。
油锅中突然窜起一团橙红色火焰，伴随大量白色油雾，火焰高度约 30cm，持续约 2 秒后回落。
周围有员工正在操作，一人迅速后退，另一人拿起锅盖试图覆盖。
背景可见其他员工和物料架，高峰期忙碌场景。
真实监控画质，顶灯照明，画面略有运动模糊（因人员快速移动）。
```

**标注要点**：
- event_type: `flame` + `smoke`
- start_frame: ~45 (1.5s 左右爆燃)
- severity: `critical`
- 注意：油雾爆燃的瞬间性，火焰颜色偏橙红

---

### B1-POS-04 · 仓库角落电线短路冒烟（白天）

```
固定监控摄像头视角，竖屏 9:16，俯视仓库/储物间一角。
仓库内货架上堆放着纸箱和包装材料，画面左侧墙面有电源插座。
插座处电线绝缘层烧焦，冒出淡蓝色烟雾，伴有轻微的电火花闪烁。
烟雾量不大，但持续稳定，颜色偏淡蓝灰。
无人员在场，画面静止，只有烟雾在缓慢飘动。
真实监控画质，白天自然光从窗户射入，画面左侧略亮。
```

**标注要点**：
- event_type: `smoke`
- start_frame: ~0 (视频开头即冒烟)
- severity: `major`
- 注意：电线短路的淡蓝色烟雾特征，区别于普通白烟

## 负样本 Prompt（Negative）

### B1-NEG-01 · 正常蒸汽（煮茶/蒸煮）

```
固定监控摄像头视角，竖屏 9:16，正对后厨蒸煮区。
奶茶店后厨，不锈钢蒸煮锅正在工作，锅盖边缘冒出大量白色蒸汽。
蒸汽呈垂直向上飘散，颜色纯白，无异味感，无黑色/灰色成分。
一名员工正常操作，揭开锅盖搅拌，蒸汽量瞬时增大，随后回落。
画面整体明亮，白天自然光+顶灯。
真实监控画质，固定机位，无异常。
```

**关键区分点**：蒸汽 = 白色、垂直上升、与蒸煮设备直接关联、无焦糊味视觉暗示

### B1-NEG-02 · 正常营业照明/反光

```
固定监控摄像头视角，竖屏 9:16，俯视门店大厅收银区。
正常营业中，灯光明亮，天花板的射灯在不锈钢台面上形成亮斑。
画面右侧玻璃门有阳光反射，形成一块移动的光斑（因门外人员经过造成光影变化）。
所有光源均为正常照明或自然光反射，无火焰、无烟雾、无异常高温发光体。
员工正常接待顾客，画面平静。
真实监控画质，白天，固定机位。
```

**关键区分点**：光影变化 ≠ 明火；反光光斑无 flicker、无热量扰动空气的视觉特征

### B1-NEG-03 · 顾客吸烟（店外/门口）

```
固定监控摄像头视角，竖屏 9:16，正对门店入口外区域。
门店门口的人行道上，一名顾客站在画面右侧，正在吸烟。
香烟前端有微弱的橙红色火星，烟雾量极少，几乎不可见。
顾客距离门店入口约 2 米，不在店内。
画面平静，白天，自然光。
真实监控画质，固定机位。
```

**关键区分点**：店外吸烟不在检测范围内；香烟火星微弱、无规模烟雾、位置在店外

### B1-NEG-04 · 正常烹饪火焰（明档/展示性）

```
固定监控摄像头视角，竖屏 9:16，正对门店明档操作区。
奶茶店明档设计，顾客可见区域有火焰表演（如焦糖布丁喷枪、炙烤芝士）。
火焰为受控的小型喷枪火焰，蓝色焰心+黄色外焰，操作人员手持设备、动作规范。
火焰持续时间约 3 秒，随后熄灭。
画面明亮，白天营业中，顾客在柜台前等待。
真实监控画质，固定机位。
```

**关键区分点**：受控明档火焰 = 预期内的正常操作、人员在场且操作规范、火焰形态受控

## 边界 Case Prompt（Edge）

### B1-EDGE-01 · 极淡烟雾/疑似蒸汽（临界状态）

```
固定监控摄像头视角，竖屏 9:16，俯视后厨操作台后方。
画面中央偏左，设备后方有极淡的灰白色气体缓慢上升。
气体量极少，几乎与背景融合，需要仔细辨认才能察觉。
颜色介于白色（蒸汽）和灰色（烟雾）之间，难以明确区分。
无人员注意到该气体，画面整体平静。
真实监控画质，白天，画面略有过曝。
```

**标注要点**：confidence_gt = 0.55，用于标定 Layer 1 触发阈值和 Layer 2 复核策略

---

### B1-EDGE-02 · 远距离微小明火（像素级）

```
固定监控摄像头视角，竖屏 9:16，广角俯视整个后厨。
后厨面积较大，画面深处（约 5 米外）角落有一个极小的橙红色光点。
光点大小约 5×5 像素，疑似小火苗或指示灯，无法确认是否为明火。
画面大部分区域正常，员工在前景操作，未注意到远处光点。
真实监控画质，夜间，画面深处有噪点。
```

**标注要点**：confidence_gt = 0.50，用于测试远距离/小目标检测能力，触发 Layer 2 局部放大复核

---

### B1-EDGE-03 · 烟雾被强风吹散（形态异常）

```
固定监控摄像头视角，竖屏 9:16，正对后厨门口区域。
后厨门口处有灰白色烟雾被强风吹入（来自室外或相邻区域），烟雾呈水平飘动而非垂直上升。
烟雾来源不明，可能来自室外、隔壁店铺或本店设备。
画面中有员工经过门口，表情正常，未表现出惊慌。
真实监控画质，白天，门口区域因室内外光线差异略有逆光。
```

**标注要点**：confidence_gt = 0.60，烟雾形态异常（水平而非垂直），来源不明，需要 Layer 2 结合时序判定

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1**（整段视频） | 所有 B1 样本均过 Layer 1 | 豆包 Vision 输出 `smoke` / `flame` / `none` + 置信度 + 时间戳 |
| **Layer 2**（局部复核） | confidence < 0.85 或 event_type 为 `smoke` 且颜色偏淡 | ffmpeg 抽帧 → 裁剪 event 区域 → 二次 Vision 判定烟雾颜色/动态 |
| **后端规则** | Layer 2 输出 `smoke`/`flame` 且持续时间 ≥ 2s | 触发告警，生成 evidence.json，严重度 `critical`/`major` |
