## 主样本 Prompt（Positive）

### A1-POS-01 · 员工未戴口罩直接操作食品（白天）

```
固定监控摄像头视角，竖屏 9:16，俯视 slightly 斜视后厨操作台。
奶茶店后厨环境，不锈钢操作台，上方有储物架。
一名员工正在操作台前制作奶茶，双手直接接触杯口和配料。
员工未佩戴口罩，口鼻完全裸露；未佩戴一次性手套，双手直接接触食品。
员工专注于操作，表情平静，似乎未意识到违规。
操作台上有奶茶杯、配料碗、吸管等物料。
真实监控画质，固定机位，白天，顶灯照明。
```

**标注要点**：
- event_type: `no_mask_or_gloves`
- sub_type: `no_mask`
- bbox: 员工面部区域 + 手部区域
- severity: `major`
- 注意：口罩是否覆盖口鼻、手套是否覆盖双手、是否直接接触食品

## 负样本 Prompt（Negative）

### A1-NEG-01 · 员工规范佩戴口罩和手套

```
固定监控摄像头视角，竖屏 9:16，俯视后厨操作台。
一名员工正在制作奶茶，规范佩戴一次性医用口罩（完全覆盖口鼻），双手佩戴一次性透明手套。
员工操作规范，手套无破损，口罩未滑落。
操作台整洁，物料摆放有序。
真实监控画质，固定机位，白天。
```

**关键区分点**：规范佩戴 = 口罩覆盖口鼻 + 手套覆盖双手 + 无破损脱落

---

### A1-NEG-02 · 员工仅在非食品接触区未戴口罩

```
固定监控摄像头视角，竖屏 9:16，正对仓库/储物区。
一名员工正在仓库整理纸箱和包装材料，未佩戴口罩和手套。
员工未接触任何食品或食品接触面，仅在处理外包装材料。
仓库区域与后厨操作区有明显分隔。
真实监控画质，固定机位，白天。
```

**关键区分点**：非食品接触区域（仓库/大厅）的未佩戴 ≠ 违规；需「直接接触食品/食品接触面」才触发

## 边界 Case Prompt（Edge）

### A1-EDGE-01 · 口罩佩戴不规范（仅覆盖口部，鼻子外露）

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
一名员工正在制作奶茶，佩戴了一次性口罩，但口罩下滑，仅覆盖口部，鼻子完全外露。
员工双手佩戴了手套，操作规范。
口罩位置明显不正确，但未完全摘除。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.60，口罩佩戴不规范（未完全覆盖口鼻）是否算违规？——建议：口鼻任一部分裸露即算违规

---

### A1-EDGE-02 · 手套破损但未察觉

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
一名员工正在操作，佩戴了口罩和一次性手套。
但右手手套食指处有轻微破损（约 1cm 裂口），员工未察觉，食指尖端裸露并接触了奶茶杯内壁。
破损很小，不仔细看难以发现。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.55，手套破损导致皮肤接触食品接触面是否算违规？——建议：破损导致皮肤直接接触即算违规

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `no_mask_or_gloves` / `compliant` + 置信度 + 面部/手部 bbox |
| **Layer 2** | confidence 0.55-0.85 | 抽帧 → 放大面部和手部区域 → 二次判定口罩覆盖度和手套佩戴状态 |
| **后端规则** | Layer 2 确认违规 | 触发告警；直接接触即食食品直接 Major，接触外包装/非食品区 Info |
