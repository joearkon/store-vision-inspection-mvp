> 规则编码：A3（操作台脏乱）+ A4（地面垃圾）
> 优先级：P1 | 类别：卫生 | 合并策略：统一为「环境卫生」能力

## 主样本 Prompt（Positive）

### A3-A4-POS-01 · 操作台严重脏乱（液体溢出 + 残渣堆积）

```
固定监控摄像头视角，竖屏 9:16，俯视 slightly 斜视后厨操作台。
不锈钢操作台表面有大量奶茶液体溢出，形成乳白色水渍，面积约 30×20cm。
台面上散落着用过的吸管包装纸、水果皮残渣、纸巾团等垃圾。
操作台边缘的器具（雪克杯、量杯）摆放混乱，未归位。
地面可见几滴溅落的液体和一张掉落的纸巾。
画面中有员工在操作台另一侧工作，似乎未注意到脏乱区域。
真实监控画质，固定机位，白天，顶灯照明。
```

**标注要点**：
- event_type: `counter_messy` + `floor_litter`
- bbox: 操作台表面区域 + 地面脏区
- severity: `major`
- 注意：液体溢出面积、垃圾种类和数量

## 负样本 Prompt（Negative）

### A3-A4-NEG-01 · 完全整洁的操作台和地面（标准 SOP）

```
固定监控摄像头视角，竖屏 9:16，俯视后厨操作台。
不锈钢操作台表面光洁，无任何液体残留或垃圾。
器具按标准位置摆放：雪克杯在左侧架，量杯在中，糖浆瓶在右侧。
地面干净，无任何污渍或垃圾。
一名员工正在规范操作，台面保持整洁。
真实监控画质，固定机位，白天，灯光明亮。
```

**关键区分点**：完全整洁，无任何异常

### A3-A4-NEG-02 · 正常操作中的瞬时凌乱（制作过程中）

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
一名员工正在制作复杂饮品（如多料奶茶），操作台上有暂时摆放的多个小料碗、量杯、搅拌勺。
物料虽多，但摆放有序，每个容器都有固定位置。
员工动作熟练，制作完成后开始清理，台面逐渐恢复整洁。
地面干净。
真实监控画质，固定机位，白天。
```

**关键区分点**：制作过程中的「有序忙碌」≠ 脏乱；有固定摆放位置、制作后会清理

### A3-A4-NEG-03 · 微小瑕疵（单滴水渍/单张纸巾）

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台表面整体干净，仅有一小滴水渍（直径约 1cm）和一张折叠整齐的干净纸巾。
地面无任何垃圾。
员工在另一侧操作，未受影响的区域占画面 95% 以上。
真实监控画质，固定机位，白天。
```

**关键区分点**：微小瑕疵不触发规则；需定义面积/数量阈值（如污渍面积 > 50cm² 或垃圾 > 3 处）

地面上整齐码放着几箱未开封的原料（牛奶箱、茶叶箱），旁边有一个干净的空周转箱。
这些是正常物料存放，不是垃圾。

**关键区分点**：正常物料/设备 ≠ 垃圾；需区分「功能性摆放」与「废弃垃圾」

## 边界 Case Prompt（Edge）

### A3-A4-EDGE-01 · 操作台「即将凌乱」临界状态

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台上有 3-4 个使用过的器具未及时归位，一小滩液体（面积约 10×5cm），两张揉皱的纸巾。
整体不算严重脏乱，但已超出「完全整洁」标准，处于临界状态。
员工正在操作，似乎暂时无暇清理。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.60，临界状态，用于标定「脏乱」阈值

---

### A3-A4-EDGE-02 · 光影造成的「假污渍」

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台表面有一块深色区域，疑似污渍，但实为头顶射灯阴影或窗外树木倒影。
光影随时间轻微移动（约 2 秒移动 1cm），证明是光影而非实体污渍。
真实监控画质，固定机位，白天，有自然光变化。
```

**标注要点**：confidence_gt = 0.40（应为负样本），测试光影干扰下的误报防控

---

### A3-A4-EDGE-03 · 清洁过程中（拖把/抹布在场）

```
固定监控摄像头视角，竖屏 9:16，俯视后厨地面。
一名员工正在用拖把清洁地面，地面上有清洁用水和少量泡沫。
拖把和水桶在画面中，员工 actively 在清洁。
地面虽有水和泡沫，但属于「正在清洁」状态，非「脏乱未处理」状态。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.30（应为负样本），测试「动作语义理解」——清洁中 ≠ 脏乱

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `counter_messy` / `floor_litter` / `clean` + 置信度 + 脏区 bbox |
| **Layer 2** | confidence 0.60-0.85 或检测到「微小瑕疵/光影干扰」 | 抽帧 → 局部放大脏区 → 二次判定污渍真实性 + 面积估算 |
| **后端规则** | Layer 2 确认 messy 且持续时间 ≥ 60s（环境类需时间累积） | 触发告警，生成 evidence.json；如持续 ≥ 300s 升级严重度 |

> **关键差异**：环境类规则必须引入「时间基线」——单次画面检测不够，需跨帧/跨时段比对确认「持续脏乱」。

## 与 E1 的对照差异

| 维度 | E1 | A3/A4 |
|------|-----|-------|
| 检测目标 | [E1] | 操作台脏乱 + 地面垃圾 |
| 最大难点 | [E1] | 污渍定义主观性强；需时间基线；光影/正常物料干扰 |
| 确认策略 | [E1] | 多帧聚合 + 面积阈值 + 时间累积 |
| 严重度 | [E1] | Major（显性脏乱）/ Minor（隐蔽污渍） |
| 延迟要求 | [E1] | ≤ 10s（P1），但后端规则需 ≥ 60s 持续才触发 |
