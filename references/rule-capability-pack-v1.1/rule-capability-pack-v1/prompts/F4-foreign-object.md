## 主样本 Prompt（Positive）

### F4-POS-01 · 头发落入饮品制作中

```
固定监控摄像头视角，竖屏 9:16，俯视 slightly 斜视操作台。
一名员工正在往奶茶杯中加料，俯身时一根头发从头侧脱落，落入敞口的奶茶杯中。
头发长度约 10cm，黑色，在奶茶表面清晰可见。
员工似乎未察觉，继续操作。
操作台为不锈钢材质，背景为后厨环境。
真实监控画质，固定机位，白天，顶灯照明。
```

**标注要点**：
- event_type: `foreign_object`
- sub_type: `hair`
- bbox: 异物位置 + 落入区域
- severity: `major`
- 注意：异物的大小、颜色、与背景的对比度

### F4-POS-02 · 昆虫飞入操作台物料中

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台上放着一碗切好的水果块（芒果、西瓜），上方无遮盖。
一只小昆虫（疑似果蝇或蚊子）从画面左上方飞入，落在水果块表面，停留约 2 秒后飞走。
昆虫体型小（约 2-3mm），但深色身体在浅色水果上可见。
员工在画面右侧操作，未注意到昆虫。
真实监控画质，固定机位，白天。
```

**标注要点**：
- event_type: `foreign_object`
- sub_type: `insect`
- severity: `major`
- 注意：昆虫体积小、移动快，检测难度高

## 负样本 Prompt（Negative）

### F4-NEG-01 · 正常配料（珍珠/椰果/果肉）

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
员工正在往奶茶中加入珍珠和椰果，配料从专用容器中倒入。
所有物料均为正常饮品配料，无异物。
操作规范，物料容器干净。
真实监控画质，固定机位，白天。
```

**关键区分点**：正常配料 ≠ 异物；需区分「预期内的食材」与「预期外的污染物」

## 边界 Case Prompt（Edge）

### F4-EDGE-01 · 微小纤维/绒毛（疑似衣物纤维）

```
固定监控摄像头视角，竖屏 9:16，俯视操作台。
操作台边缘有一根极细的白色纤维（长度约 5mm，直径 < 0.5mm），疑似衣物绒毛或纸巾纤维。
纤维非常细小，几乎与不锈钢台面的反光融为一体，需要仔细辨认。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.45，微小纤维是否算「异物」？——建议：可见且 > 3mm 的纤维算，更小或不可见的忽略

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `foreign_object` / `clean` + 置信度 + 异物类型 + 位置 bbox |
| **Layer 2** | confidence 0.55-0.85 或异物极小/移动快 | 抽帧 → 放大异物区域 → 二次判定异物类型和大小 |
| **后端规则** | Layer 2 确认异物且大小 > 3mm | 触发告警；异物落入食品中直接 Major |
