## 主样本 Prompt（Positive）

### A6-POS-01 · 消防通道堆满货物箱（白天）

```
固定监控摄像头视角，竖屏 9:16，正对门店后方的消防通道/安全出口。
通道宽约 1.5 米，地面为灰色防滑地砖，上方有绿色安全出口指示牌。
通道中央和两侧堆放着多个纸箱和塑料周转箱（约 8-10 个），占据了通道约 70% 的宽度。
箱子堆叠高度约 60cm，部分箱子倾斜，随时可能倒塌。
通道尽头的安全出口门被箱子部分遮挡，门把手可见但前方有障碍物。
无人员在通道中，画面静止。
真实监控画质，固定机位，白天，顶灯+安全出口指示灯照明。
```

**标注要点**：
- event_type: `passage_blocked`
- bbox: 通道区域 + 障碍物区域
- severity: `major`
- 注意：障碍物占比、通道剩余宽度、是否遮挡安全出口

固定监控摄像头视角，竖屏 9:16，俯视后厨通往仓库的走道。

## 负样本 Prompt（Negative）

### A6-NEG-01 · 完全畅通的通道

```
固定监控摄像头视角，竖屏 9:16，正对消防通道。
通道完全畅通，无任何障碍物，地面干净。
安全出口指示牌清晰可见，出口门无遮挡。
一名员工正常快步通过，无需绕行。
真实监控画质，固定机位，白天。
```

---

### A6-NEG-02 · 临时短暂放置（员工正在搬运）

```
固定监控摄像头视角，竖屏 9:16，俯视后厨走道。
一名员工正推着一辆原料车通过走道，车辆占据走道约 50% 宽度但正在移动中。
员工 actively 在搬运，非静止堆放。
5 秒后员工和车辆离开画面，走道恢复畅通。
真实监控画质，固定机位，白天。
```

**关键区分点**：临时通过中的移动物体 ≠ 堵塞；需「静止障碍物 + 持续 ≥ X 秒」

## 边界 Case Prompt（Edge）

### A6-EDGE-01 · 通道边缘摆放（不占主通道）

```
固定监控摄像头视角，竖屏 9:16，俯视走道。
走道宽约 1.2 米，左侧靠墙处整齐码放着 3 个原料箱（约占宽度 20%）。
走道中央剩余约 0.9 米宽度，两人可正常并排通过。
箱子摆放整齐，不倾倒，不阻碍安全出口。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.50，通道边缘少量占用是否算堵塞？——建议：主通道宽度 < 0.8m 或占用 > 50% 算堵塞

---

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `passage_blocked` / `clear` + 置信度 + 障碍物 bbox |
| **Layer 2** | confidence 0.60-0.85 | 抽帧 → 测量通道剩余宽度比例 → 二次判定 |
| **后端规则** | Layer 2 确认 blocked 且持续时间 ≥ 300s | 触发告警；如遮挡安全出口直接 Critical |
