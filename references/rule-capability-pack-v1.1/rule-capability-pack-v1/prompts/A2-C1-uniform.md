# A2/C1 · 着装类检测 · Video Prompt

> 规则编码：A2（未戴工帽/发网）+ C1（未穿围裙/工服）
> 优先级：P1 | 类别：合规 | 合并策略：统一为「着装规范」能力
> 对应 MVP §4.1 正式规则

---

## 通用参数（所有样本共用）

| 参数 | 值 | 说明 |
|------|-----|------|
| 分辨率 | 1080×1920 | 竖屏 9:16 |
| 帧率 | 30 fps | |
| 时长 | 主样本 8-10s / 负样本 5-8s / 边界 6-10s | |

## 主样本 Prompt（Positive）

### A2-C1-POS-01 · 未戴工帽 + 未穿围裙（正面）

```
固定监控摄像头视角，竖屏 9:16，正面平视后厨操作台。
一名年轻男性员工站在操作台前备料，头发散乱露出，未戴工帽或发网。
上身穿着自己的黑色 T 恤，未穿统一围裙或工服。
下身穿着深色裤子，脚穿运动鞋。
员工动作正常，正在搅拌杯中饮品，未意识到被拍摄。
后厨背景为不锈钢操作台和物料架，灯光明亮。
真实监控画质，固定机位，白天营业中。
```

**标注要点**：
- event_type: `hat_missing` + `apron_missing`
- bbox: 头部区域（工帽缺失）+ 躯干区域（围裙缺失）
- severity: `major`

## 负样本 Prompt（Negative）

固定监控摄像头视角，竖屏 9:16，正面平视操作台。
一名员工规范着装：头上戴白色工帽，头发完全收束；上身穿着统一深蓝色工服，外系米色围裙。

**关键区分点**：全部着装要素完整，无缺失

## 边界 Case Prompt（Edge）

### A2-C1-EDGE-01 · 工帽戴但不规范（歪斜/半脱落）

```
固定监控摄像头视角，竖屏 9:16，正面平视后厨。
一名员工戴着工帽，但帽子歪斜，部分头发从边缘露出。
工服和围裙穿戴规范。
员工正在快速移动中，帽子随动作晃动，偶尔露出更多头发。
真实监控画质，固定机位，白天，有轻微运动模糊。
```

**标注要点**：confidence_gt = 0.65，「戴了但不规范」 vs 「完全未戴」的临界状态

---

### A2-C1-EDGE-02 · 远距离/背影，着装难以辨认

```
固定监控摄像头视角，竖屏 9:16，广角俯视整个后厨。
画面深处（约 4-5 米）有一名员工背影，因距离较远，头部和上身细节模糊。
似乎穿着深色上衣，但无法确认是否为工服；似乎头部有遮盖，但无法确认是否为工帽。
真实监控画质，白天，远处有轻微模糊。
```

**标注要点**：confidence_gt = 0.50，像素级模糊，测试检测下限，应触发 Layer 2 或标记为不可判定

---

### A2-C1-EDGE-03 · 部分身体被遮挡（物料架/设备遮挡上半身）

```
固定监控摄像头视角，竖屏 9:16，侧面斜视后厨。
一名员工站在物料架后方操作，头部和肩膀可见，但躯干下半部分被物料架遮挡。
头部可见戴着工帽，但围裙是否穿戴不可见（被遮挡）。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.60，部分可见部分不可见，测试遮挡处理策略

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | 豆包 Vision 输出 `hat_missing` / `apron_missing` / `uniform_missing` / `compliant` + 置信度 |
| **Layer 2** | confidence 0.60-0.85 或检测到「部分遮挡/不规范穿戴」 | 抽帧 → 放大人物上半身 → 二次判定着装细节 |
| **后端规则** | Layer 2 确认 missing 且持续时间 ≥ 5s（非瞬时） | 触发告警，生成 evidence.json，严重度按缺失类型分级 |

## 与 E1 的对照差异

| 维度 | E1 | A2/C1 |
|------|-----|-------|
| 检测目标 | [E1] | 工帽/发网 + 围裙/工服 |
| 最大难点 | [E1] | 多姿态/遮挡/相似服饰区分；顾客 vs 员工身份区分 |
| 确认策略 | [E1] | 需人物检测前置 + 上半身区域聚焦 |
| 严重度 | [E1] | Major（完全缺失）/ Minor（不规范） |
| 延迟要求 | [E1] | ≤ 10s（P1） |
