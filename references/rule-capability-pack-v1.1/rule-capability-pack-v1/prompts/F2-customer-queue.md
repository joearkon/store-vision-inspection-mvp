## 主样本 Prompt（Positive）

### F2-POS-01 · 收银区排长队（高峰期）

```
固定监控摄像头视角，竖屏 9:16，俯视 slightly 斜视门店收银区/点单区。
收银台位于画面右侧，一名收银员正在操作 POS 机。
收银台前排队等待的顾客约 8-10 人，队伍从收银台一直延伸到画面左侧门口区域。
顾客之间间距很小（约 30-50cm），部分人紧挨在一起。
队伍无明显秩序，部分顾客侧身交谈，队伍呈 S 形弯曲。
有 1-2 名顾客面露不耐烦，正在看手表或手机。
门店大厅其他座位区也有较多顾客，整体氛围拥挤。
真实监控画质，固定机位，白天，灯光明亮。
```

**标注要点**：
- event_type: `customer_queue_congestion`
- bbox: 排队区域 + 顾客人群区域
- severity: `major`
- 注意：排队人数、队伍长度、顾客间距、等待时间表现（不耐烦表情/动作）

### F2-POS-02 · 门口拥挤（订单爆发）

```
固定监控摄像头视角，竖屏 9:16，正对门店入口区域。
门店门口聚集了约 6-8 名顾客，有的在等待取餐，有的在排队点单。
门口区域狭小（约 2×3 米），顾客密度高，人与人之间的距离不足 50cm。
部分顾客站在门口阻挡了进出通道，新顾客进门困难。
一名外卖骑手也挤在门口，手持手机核对订单号。
真实监控画质，固定机位，白天。
```

**标注要点**：
- event_type: `customer_queue_congestion`
- severity: `minor`

## 负样本 Prompt（Negative）

### F2-NEG-01 · 正常排队秩序

```
固定监控摄像头视角，竖屏 9:16，俯视收银区。
收银台前有约 4-5 名顾客排队，队伍整齐，顾客之间保持约 1 米间距。
地面有清晰的「请在一米线外等候」标识，顾客自觉站在标识后。
收银员操作流畅，顾客等待时间较短，无人表现出不耐烦。
门店其他区域宽敞，无拥挤感。
真实监控画质，固定机位，白天。
```

**关键区分点**：人数适中 + 间距合理 + 秩序良好 + 顾客情绪平静

## 边界 Case Prompt（Edge）

### F2-EDGE-01 · 人数多但间距大（宽敞门店）

```
固定监控摄像头视角，竖屏 9:16，俯视大型门店收银区。
收银台前有约 10 名顾客排队，但门店空间宽敞（面积约 80 平米）。
顾客之间保持约 1.2 米间距，队伍笔直有序，无拥挤感。
顾客表情平静，无人表现出不耐烦。
真实监控画质，固定机位，白天。
```

**标注要点**：confidence_gt = 0.50，人数多但空间充裕、间距大是否算「拥挤」？——建议：以「人均占地面积 < 1 平米」或「排队等待时间 > 5 分钟表现」为核心判定

## 双层判定对接说明

| 层级 | 触发条件 | 处理方式 |
|------|----------|----------|
| **Layer 1** | 所有样本过 Layer 1 | Vision 输出 `queue_congestion` / `normal` + 置信度 + 人群 bbox + 人数估算 |
| **Layer 2** | confidence 0.55-0.85 | 抽帧 → 测量顾客间距和队伍长度 → 二次判定拥挤程度 |
| **后端规则** | Layer 2 确认拥挤且持续 ≥ 180s | 触发告警；人均面积 < 0.5 平米或排队 > 10 人直接 Major |
