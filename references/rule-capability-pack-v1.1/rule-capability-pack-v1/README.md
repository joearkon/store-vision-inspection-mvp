## 使用方法

### 1. 视频样本生成流程

每条规则的 `prompts/*.md` 文件包含：
- **主样本 Prompt**：规则触发的典型场景（≥3 段，覆盖不同角度/光照/时段）
- **负样本 Prompt**：规则未触发的对照场景（≥3 段，覆盖常见误报源）
- **边界 Case Prompt**：模糊/临界状态（≥2 段，用于标定阈值）
- **通用参数**：分辨率、帧率、时长、风格约束、平台限制提醒
- **参考图链接**：视觉基线（如有）

**执行步骤：**
1. 复制对应规则的 Prompt 到视频生成平台（豆包/可灵/海螺/Minimax）
2. 严格遵循「通用参数」中的平台限制（如 Minimax 单段 ≤5s，海螺 ≤10s 等）
3. 生成后按 `golden-set-spec.md` 进行标注
4. 命名规范：`{rule-id}_{sample-type}_{index}.mp4`，如 `B1_positive_01.mp4`

### 2. 能力设计与双层判定对接

每条规则的 `designs/*.md` 文件包含：
- **能力类型**：检测型 / 分类型 / 时序型
- **确认策略**：单帧确认 / 多帧聚合 / 时序累积
- **严重度分级**：Critical / Major / Minor / Info
- **边界 Case**：≥3 个典型模糊场景
- **双层判定对接**：
  - Layer 1（整段视频 URL → AI 初判）：触发条件、输出格式
  - Layer 2（局部复核 → 精确框定）：触发条件、裁剪策略、二次判定规则
  - 后端确定性规则：硬编码兜底逻辑
- **Golden Set 规模建议**：正/负/边界样本数量

### 3. 与 E1 的对照

E1 已实现完整的端到端流程（主样本 50s + 负样本 15s），其 `artifacts/e1-video-prompt-v1.md` 为格式母版。本包所有 Prompt 文件沿用同一格式。

E1 的双层判定架构已验证：
- Layer 1：整段视频 URL 送入豆包 Vision，输出 event 类型 + 置信度 + 时间戳
- Layer 2：置信度 < 0.85 或触发复核规则时，ffmpeg 抽帧 → 局部裁剪 → 二次 Vision 判定
- 后端：确定性规则过滤（如面积阈值、持续时间阈值）
- evidence.json：全程留痕，含原始帧、判定结果、规则命中路径

本包所有新规则均对接同一架构，仅 Layer 1/2 的触发条件和后端阈值不同。
