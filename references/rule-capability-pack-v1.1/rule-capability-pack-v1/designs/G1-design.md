# G1 · 餐桌残留检测 · 能力设计

> 规则编码：G1 | 优先级：P2（实验规则）
> 对应 MVP §4.2 实验规则 | 检测目标：顾客离席后餐桌上的食物残渣、餐具未收、纸巾/垃圾遗留
> **复杂度最高**：需同时处理「人物检测 + 物品检测 + 时序理解 + 状态分类」四重叠加

---

## 1. 能力类型

| 维度 | 定义 |
|------|------|
| **检测类型** | 检测型 + 时序型 + 分类型（四重叠加） |
| **输入** | 视频片段（10-15s，固定机位监控画面） |
| **输出** | 残留状态（`table_residual` / `clean` / `in_use`）+ 残留物列表（类型/数量/位置）+ 置信度 |
| **核心能力** | 在顾客离席后识别桌面残留物，并排除「使用中」「清洁中」「固定摆件」等干扰 |

### 1.1 检测目标细分（残留物类型）

| 子类型 | 定义 | 示例 |
|--------|------|------|
| `cup` | 饮品杯具 | 奶茶杯、咖啡杯、空杯、半满杯 |
| `bowl` | 碗/盘 | 甜品碗、蛋糕盘、空碗 |
| `tissue` | 纸巾 | 使用过的纸巾团、纸巾盒（需区分） |
| `wrapper` | 包装纸 | 吸管包装、糖包、调味品包装 |
| `food_residual` | 食物残渣 | 珍珠、椰果、蛋糕碎屑、水果块 |
| `spill` | 液体污渍 | 洒落的奶茶、水渍、奶油痕迹 |
| `fixed_item` | 固定摆件（排除） | 桌号牌、装饰盆栽、菜单立牌、调味品罐 |

## 2. 确认策略

### 2.1 分层确认架构

```
前置步骤 1：人物检测
  └── 检测餐桌周围是否有人员就座
        ├── 有人就座 → 标记为 in_use，跳过残留检测
        └── 无人就座 → 进入前置步骤 2

前置步骤 2：离席判定（时序理解）
  └── 分析视频时序：人员从「在座」→「起身」→「离开画面」
        ├── 确认离席（人员消失 ≥ 3s）→ 进入 Layer 1
        └── 人员未完全离开（如在邻桌站立）→ 标记为 in_use

Layer 1（整段视频）
  └── 豆包 Vision 初判：桌面物品检测 + 状态分类
        ├── confidence ≥ 0.85 且检测到残留物 ≥ 3 件
        │     └── 进入 Layer 2
        ├── confidence 0.50-0.85 或残留物少/隐蔽
        │     └── 进入 Layer 2
        └── confidence < 0.50 或无残留物
              └── 标记为 clean

Layer 2（局部复核）
  └── 抽帧 → 放大桌面区域 → 二次 Vision 判定
        ├── 确认残留物类型和数量
        │     └── 进入后端规则
        └── 判断为固定摆件/清洁中/使用中
              └── 不触发

后端确定性规则
  └── 硬编码兜底 + 时间累积
        ├── 顾客离席后持续 ≥ 120s 未清理且残留物 ≥ 3 件 → Minor
        ├── 顾客离席后持续 ≥ 300s 未清理或残留物 ≥ 5 件/面积 > 30% 桌面 → Major
        └── 检测到员工清洁动作 → 重置计时
```

### 2.2 时序理解策略（G1 核心）

G1 是 MVP 中唯一需要「时序理解」的规则：

```
时序状态机：
  [有人就座] --离席--> [空桌待检] --检测残留--> [有残留计时] --员工清理--> [干净]
                              |                            |
                              |--无残留--> [干净]          |--超时--> [告警]
```

- **离席判定**：人员 bbox 从餐桌区域消失 ≥ 3s（避免短暂起身拿东西误判）
- **计时起点**：离席确认后，首次检测到残留物的时刻
- **计时终点**：员工清洁动作检测 或 桌面变干净
- **采样策略**：每 60s 采样一次（顾客离席后不需要高频检测）

## 3. 严重度分级

| 严重度 | 条件 | 响应动作 | 通知渠道 |
|--------|------|----------|----------|
| **Major** | 残留物 ≥ 5 件 或 覆盖 > 30% 桌面 或 持续 ≥ 300s | 告警 + 推 SaaS Dashboard + 飞书 IM | IM + SaaS |
| **Minor** | 残留物 3-4 件 且 持续 ≥ 120s | 仅推 SaaS Dashboard | SaaS |
| **Info** | 残留物 1-2 件 或 隐蔽残留 | 仅入 evidence.json | 无 |

## 4. 边界 Case（≥3 个）

### Case 1：空杯是否算残留？

- **场景**：顾客离席后，桌上只有一个干净的空奶茶杯（杯盖盖好，无液体）
- **争议**：空杯是垃圾还是可回收器具？
- **处理**：
  - 规则定义：空杯 + 杯盖盖好 + 无残液 → **不算残留**（Info 级别记录但不告警）
  - 开盖/有残液/多个空杯 → 算残留
  - Layer 2 复核时增加判别："杯子是否开盖？是否有液体残留？"

### Case 2：跨桌物品转移

- **场景**：A 桌顾客离席，桌上有两杯奶茶。B 桌顾客（同行人）伸手拿走一杯，A 桌最终剩一杯。
- **风险**：静态画面无法判断「物品转移」的时序因果关系
- **处理**：
  - 依赖视频时序分析：检测 B 桌人员伸手 → 物品从 A 桌消失的动作链
  - 如检测到转移动作，以最终桌面状态为准（剩余 1 杯）
  - 如未检测到转移动作（摄像头角度看不到），保守判定为「有残留」

### Case 3：固定摆件 vs 顾客遗留物

- **场景**：桌面有桌号牌、装饰盆栽、调味品罐（门店固定陈设）+ 顾客留下的奶茶杯
- **风险**：误将固定摆件计入残留物数量
- **处理**：
  - 维护「门店固定摆件白名单」：桌号牌、装饰盆栽、菜单、调味品罐等
  - Layer 1 Prompt 增加要求："区分门店固定摆件和顾客遗留物"
  - 固定摆件不计入残留物数量

## 5. 与双层判定架构的对接

### 5.1 Layer 1（整段视频 URL → AI 初判）

| 字段 | 说明 |
|------|------|
| 输入 | 视频 URL（10-15s mp4，需覆盖「顾客在座 → 离席 → 桌面暴露」完整时序） |
| 触发条件 | 所有样本过 Layer 1 |
| Prompt 指令 | "分析这段餐厅监控视频：1) 识别餐桌周围的人员状态（在座/起身/离席）；2) 如人员已离席，识别桌面上的所有物品；3) 区分顾客遗留物（杯具/纸巾/食物残渣）和门店固定摆件（桌号牌/装饰/调味品）；4) 输出残留物列表（类型/数量/位置）和置信度" |
| 输出格式 | JSON：`{"person_status": "left", "residuals": [{"type": "cup", "count": 2, "location": "桌面中央"}, {"type": "tissue", "count": 3}], "fixed_items": [{"type": "table_number", "location": "桌角"}], "confidence": 0.82}` |

### 5.2 Layer 2（局部复核）

| 字段 | 说明 |
|------|------|
| 触发条件 | confidence 0.50-0.85；或残留物种类复杂/混叠；或疑似固定摆件 |
| 裁剪策略 | 以桌面中心裁剪 800×800 区域（桌面通常占画面主体） |
| 二次 Prompt | "放大观察这张桌面的细节。对每一个可见物品：1) 判断类型（cup/bowl/tissue/wrapper/food/spill/fixed_item）；2) 判断是否为顾客遗留物；3) 估算数量。特别注意：区分空杯（盖好盖、无液体）和有残留杯；区分使用过的纸巾和干净的纸巾盒。输出：物品清单（含类型/是否残留/数量）" |
| 输出格式 | JSON：`{"items": [{"type": "cup", "is_residual": true, "reason": "开盖且有残余液体"}, {"type": "tissue", "is_residual": true, "reason": "揉皱且使用过"}, {"type": "table_number", "is_residual": false, "reason": "门店固定摆件"}]}` |

### 5.3 后端确定性规则

```python
class TableResidualMonitor:
    """G1 餐桌残留监控"""
    def __init__(self):
        self.tables = {}  # table_id -> {status, residual_count, timer_sec, last_update}

    def update(self, table_id, layer_result, timestamp):
        """每次 Layer 1/2 结果更新时调用（采样间隔 60s）"""
        if table_id not in self.tables:
            self.tables[table_id] = {'status': 'unknown', 'timer_sec': 0}

        table = self.tables[table_id]
        person_status = layer_result.get('person_status')

        # 有人就座：重置
        if person_status == 'seated':
            table['status'] = 'in_use'
            table['timer_sec'] = 0
            return []

        # 员工清洁中：重置
        if layer_result.get('cleaning_detected'):
            table['status'] = 'clean'
            table['timer_sec'] = 0
            return []

        # 人员离席：开始计时
        if person_status == 'left':
            residuals = [i for i in layer_result.get('items', [])
                        if i.get('is_residual')]
            residual_count = sum(i.get('count', 1) for i in residuals)

            if residual_count == 0:
                table['status'] = 'clean'
                table['timer_sec'] = 0
                return []

            table['timer_sec'] += 60
            table['residual_count'] = residual_count

            # 严重度判定
            if residual_count >= 5 or table['timer_sec'] >= 300:
                return [{'table_id': table_id, 'severity': 'major',
                         'residual_count': residual_count,
                         'duration_sec': table['timer_sec']}]
            elif residual_count >= 3 and table['timer_sec'] >= 120:
                return [{'table_id': table_id, 'severity': 'minor',
                         'residual_count': residual_count,
                         'duration_sec': table['timer_sec']}]

        return []
```

## 6. Golden Set 规模建议

| 类型 | 数量 | 说明 |
|------|------|------|
| 正样本（典型残留） | ≥ 10 段 | 杯具+纸巾+食物残渣组合 |
| 正样本（大量残留） | ≥ 5 段 | 聚餐后多人物品堆积 |
| 正样本（隐蔽残留） | ≥ 5 段 | 少量/隐蔽残留物 |
| 负样本（干净空桌） | ≥ 10 段 | 完全无残留 |
| 负样本（使用中） | ≥ 5 段 | 顾客在座，物品正常使用中 |
| 负样本（清洁中） | ≥ 5 段 | 员工 actively 收拾桌面 |
| 负样本（固定摆件） | ≥ 5 段 | 仅门店固定摆件，无顾客遗留 |
| 边界样本 | ≥ 10 段 | 仅空杯、跨桌转移、水渍、光影 |
| **合计** | **≥ 55 段** | 建议 ≥ 60 |
