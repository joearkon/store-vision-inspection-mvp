# B1 · 烟雾 / 明火检测 · 能力设计

> 规则编码：B1 | 优先级：P0（高危安全事件）
> 对应 MVP §4.1 正式规则

---

## 1. 能力类型

| 维度 | 定义 |
|------|------|
| **检测类型** | 时序型 + 检测型 |
| **输入** | 视频片段（8-10s，固定机位监控画面） |
| **输出** | event_type（`smoke` / `flame` / `none`）+ 置信度 + 时间戳 + bbox（可选） |
| **核心能力** | 在复杂后厨环境中区分「烟雾/明火」与「蒸汽/光影/正常火焰」 |

### 1.1 检测目标细分

| 子类型 | 定义 | 视觉特征 |
|--------|------|----------|
| `flame` 明火 | 可见火焰，包括油火、电气火、物料燃烧 | 橙黄色/红色发光体、 flicker 动态、向上窜动、有热量扰动 |
| `smoke` 烟雾 | 可见烟雾，包括阴燃烟、电线短路烟、燃烧烟 | 灰白色/灰黑色气柱、持续上升或飘散、半透明、有体积感 |

## 2. 确认策略

### 2.1 分层确认架构

```
Layer 1（整段视频）
  └── 豆包 Vision 初判：输出 event_type + confidence
        ├── confidence ≥ 0.90 且 event_type = flame/smoke
        │     └── 直接触发后端规则（跳过后端面积/持续时间校验）
        ├── confidence 0.70-0.90
        │     └── 进入 Layer 2 局部复核
        └── confidence < 0.70
              └── 标记为 none，记录日志（用于后续模型迭代）

Layer 2（局部复核）
  └── ffmpeg 抽帧 → 裁剪 event 区域 → 二次 Vision 判定
        ├── 二次 confidence ≥ 0.85
        │     └── 确认触发，进入后端规则
        └── 二次 confidence < 0.85
              └── 人工复核队列（低优先级）

后端确定性规则
  └── 硬编码兜底逻辑
        ├── flame：任何明火直接 Critical，无持续时间门槛
        └── smoke：面积 > 100px² 且持续时间 ≥ 2s → Major
```

### 2.2 多帧聚合策略

- **火焰检测**：采用「连续 3 帧命中」策略（约 100ms），因火焰 flicker 特征需要跨帧验证
- **烟雾检测**：采用「持续 2s 累积」策略（约 60 帧），因烟雾可能短暂出现后消散（如蒸汽）
- **帧采样**：Layer 1 每 0.5s 抽 1 帧送 Vision（降低 API 调用量），Layer 2 全帧率分析

## 3. 严重度分级

| 严重度 | 条件 | 响应动作 | 通知渠道 |
|--------|------|----------|----------|
| **Critical** | 明火（flame）任何置信度 | 立即告警 + 推送飞书 IM（严重档卡片）+ 深链 SaaS Dashboard | IM + SaaS |
| **Major** | 烟雾（smoke）confidence ≥ 0.85 且持续 ≥ 2s | 告警 + 推 SaaS Dashboard + 飞书 IM（标准档） | IM + SaaS |
| **Minor** | 烟雾 confidence 0.70-0.85 | 仅记录 SaaS，不入 IM | SaaS 仅记录 |
| **Info** | 疑似但 confidence < 0.70 | 仅入 evidence.json，不告警 | 无 |

## 4. 边界 Case（≥3 个）

### Case 1：蒸汽 vs 烟雾区分

| 属性 | 蒸汽 | 烟雾 |
|------|------|------|
| 颜色 | 纯白 | 灰白/灰黑 |
| 动态 | 垂直上升，速度快 | 可垂直可水平，速度较慢 |
| 来源关联 | 与蒸煮设备直接关联 | 来源不明或来自角落/设备后方 |
| 消散 | 快速消散（< 3s） | 持续稳定 |
| 视觉质感 | 轻薄、透明 | 较厚重、半透明 |

**处理策略**：Layer 2 复核时增加「颜色判别」prompt："判断该气体的颜色偏向白色还是灰色，以及消散速度"

### Case 2：光影/反光 vs 明火

| 属性 | 光影/反光 | 明火 |
|------|----------|------|
| flicker | 无或缓慢（> 2s 周期） | 快速（< 0.5s 周期） |
| 热量扰动 | 无 | 有（空气扭曲） |
| 位置 | 平面反射（台面/玻璃） | 立体发光体 |
| 颜色一致性 | 与光源一致 | 橙黄+焰心蓝白 |

**处理策略**：后端规则增加 flicker 检测算法（帧间像素变化频率分析）

### Case 3：远距离/小像素明火

- **场景**：广角画面中 5×5 像素级别的微小火苗
- **风险**：漏报（太小看不见）或误报（把指示灯当火苗）
- **处理**：
  - Layer 1：正常过，confidence 通常较低（0.50-0.70）
  - Layer 2：自动触发（因 confidence < 0.85），局部放大 4x 后二次判定
  - 后端：如 Layer 2 仍无法确认，标记为「不可判定」入 evidence.json，不告警但留痕

## 5. 与双层判定架构的对接

### 5.1 Layer 1（整段视频 URL → AI 初判）

| 字段 | 说明 |
|------|------|
| 输入 | 视频 URL（8-10s mp4） |
| 触发条件 | 所有 B1 样本均过 Layer 1（无豁免） |
| Prompt 指令 | "分析这段监控视频，判断是否有烟雾或明火。注意区分蒸汽和光影干扰。输出：1) 事件类型（smoke/flame/none）；2) 置信度 0-1；3) 首次出现时间戳；4) 简要描述" |
| 输出格式 | JSON：`{"event_type": "smoke", "confidence": 0.92, "first_seen_sec": 2.1, "description": "操作台后方有灰白色烟雾持续上升"}` |

### 5.2 Layer 2（局部复核）

| 字段 | 说明 |
|------|------|
| 触发条件 | confidence 0.70-0.90；或 event_type = smoke 但颜色偏淡；或 bbox 像素 < 50×50 |
| 裁剪策略 | ffmpeg 抽帧 → 以 event 中心点裁剪 400×400 区域 → 如超出画面边界则取最大可用 |
| 二次 Prompt | "放大观察这个区域，判断是否为真实的烟雾或明火。重点看：颜色（白/灰/黑）、动态（上升/飘散/静止）、质感（轻薄/厚重）。输出：1) 确认结果（confirmed/denied/uncertain）；2) 置信度；3) 判别依据" |
| 输出格式 | JSON：`{"result": "confirmed", "confidence": 0.88, "reason": "颜色偏灰黑，持续上升，质感厚重，排除蒸汽"}` |

### 5.3 后端确定性规则

```python
def b1_backend_rule(layer1_result, layer2_result=None):
    """
    B1 后端确定性规则
    """
    # 明火：任何确认直接 Critical
    if layer1_result['event_type'] == 'flame' and layer1_result['confidence'] >= 0.70:
        return {'alert': True, 'severity': 'critical', 'reason': '明火 detected'}

    # 烟雾：需面积 + 持续时间双重校验
    if layer1_result['event_type'] == 'smoke':
        if layer2_result and layer2_result['result'] == 'confirmed':
            if layer2_result['confidence'] >= 0.85:
                return {'alert': True, 'severity': 'major', 'reason': '烟雾 confirmed'}
        elif layer1_result['confidence'] >= 0.90:
            # 高置信度可跳过 Layer 2
            return {'alert': True, 'severity': 'major', 'reason': '烟雾 high confidence'}

    return {'alert': False, 'severity': None, 'reason': 'No alert'}
```

## 6. Golden Set 规模建议

| 类型 | 数量 | 说明 |
|------|------|------|
| 正样本（明火） | ≥ 15 段 | 不同火源（油火/电气火/物料火）、不同场景 |
| 正样本（烟雾） | ≥ 15 段 | 不同烟源（阴燃/短路/燃烧）、不同颜色/浓度 |
| 负样本（蒸汽） | ≥ 10 段 | 蒸煮设备正常工作 |
| 负样本（光影） | ≥ 10 段 | 反光/灯光变化/窗外阳光 |
| 负样本（正常火焰） | ≥ 5 段 | 明档喷枪/炙烤等受控火焰 |
| 负样本（其他） | ≥ 5 段 | 店外吸烟、指示灯等 |
| 边界样本 | ≥ 15 段 | 极淡烟雾、远距离微火、蒸汽临界态、光影临界态 |
| **合计** | **≥ 75 段** | |
